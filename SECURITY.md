# Security Policy

## Supported versions

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Do not expose this application to the public internet. The server has no authentication and is intended only for trusted local networks. Anyone with network access can play, upload, trim, and delete audio.

For a suspected vulnerability, please do not publish exploit details in a public issue. Use GitHub's private vulnerability reporting for this repository when available. Until a private reporting channel is configured, do not include sensitive information in an issue and contact the repository maintainers directly.
