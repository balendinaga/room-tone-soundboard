# Code of Conduct

We want participation in this project to be welcoming, respectful, and constructive.

Expected behavior:

- Be considerate and patient.
- Critique ideas and code, not people.
- Respect different experiences and communication styles.
- Keep discussions relevant and share only content you have permission to distribute.

Unacceptable behavior includes harassment, personal attacks, discriminatory language, threats, and publishing another person's private information. Project maintainers may edit or remove harmful content and may restrict participation when necessary.

Report conduct concerns privately to the repository maintainers. Do not post private information in a public issue.
