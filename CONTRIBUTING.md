# Contributing

Thank you for helping improve Room Tone Soundboard.

## Before opening an issue

- Search existing issues for the same problem or suggestion.
- For bugs, include your operating system, Node.js version, steps to reproduce, and relevant logs. Do not attach private audio unless you have permission to share it.
- Never include passwords, tokens, private network details, or personal audio in an issue.

## Pull requests

1. Create a focused branch from the default branch.
2. Keep changes scoped and preserve the active app's English/Turkish behavior.
3. Run `npm ci` and `npm run check` before submitting.
4. Describe the user-visible change and note any security or compatibility impact.

Changes that expose the server to the public internet or add telemetry require explicit discussion first.
